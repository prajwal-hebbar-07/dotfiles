# Requirements: todo

- R1. Add a task. Given an empty list, when I add "buy milk", then the list shows one open task "buy milk".
- R2. Complete a task. Given an open task, when I complete it, then it is shown as done.
- R3. Delete a task. Given a task, when I delete it, then it no longer appears in the list.
- R4. Persist tasks. Given tasks were saved, when the app restarts, then the same tasks are listed.

Out of scope: accounts, sync, due dates.
