# factory-reset

Run from the target repo root. State tool:
`FS=~/.omp/agent/skills/factory/scripts/factory-state`. Board tool:
`BOARD=~/.omp/agent/skills/factory-issues/scripts/board`. `<repo>` is the
basename of the repo root. Schema of what is wiped: `skill://factory/state.md`.

## Never

- Touch product code, `AGENTS.md`, CI, check scripts, the `verify-<app>`
  skill, labels, or branch protection. Code the factory merged stays; the
  next run treats it as an existing repo.
- Stash, discard, or commit the user's uncommitted work.
- Delete a `feature/*` branch the factory did not create (only
  `feature/<slug>` for a slug in `.factory/feature/` or `state.feature`).
- Push the default branch. The user pushes the docs-removal commit.
- Change anything before the user approves, or on any answer but Approve.

## 1. Inventory (read only)

1. `git rev-parse --show-toplevel` is the cwd. `git status --porcelain`
   prints nothing (`.factory/` and `qa-evidence/` are excluded, so they do
   not count). Dirty: list the files, tell the user to commit or stash them,
   and stop.
2. Default branch: `git symbolic-ref --short refs/remotes/origin/HEAD`
   (strip `origin/`), else
   `gh repo view --json defaultBranchRef --jq .defaultBranchRef.name`.
3. Collect, each may be empty:
   - **Run state:** `.factory/` (state, ledger, board cache, handoffs,
     feature briefs); `$FS get stage` and `mode` when `state.json` exists.
   - **Holdouts:** `~/.omp/factory/<repo>/` and
     `~/.cursor/factory/holdout/<repo>/`. **Evidence:** `qa-evidence/`.
   - **Docs** (tracked only, `git ls-files`): `docs/factory/`,
     `paper-design-prompt.md`, and the `docs/architecture/diagrams/` files
     `docs/factory/ARCHITECTURE.md` links (each `.html` plus its same-slug
     `.json`).
   - **Branches:** `factory/*` plus `feature/<slug>` for each slug above,
     local (`git branch --list`) and on origin
     (`git ls-remote --heads origin`). For each local one, the commits not on
     origin (`git log --oneline origin/<b>..<b>`, or `<default>..<b>` when
     origin lacks it): these are lost.
   - **PRs:** open PRs whose head is one of those branches
     (`gh pr list --state open --json number,title,headRefName`).
   - **Issues and board:** `"$BOARD" reset --dry-run`.
4. Nothing in any list: say "no factory run here" and stop.

## 2. Confirm

Print the inventory in chat, grouped as above, with counts and the lost
commits per branch. Then one `ask`: id `reset`, header `Reset`, question
`Wipe the factory run in <repo>?`, options exactly `No` then `Approve`, no
`recommended`. Other, a typed answer, or a cancelled dialog is No: say
nothing was changed and stop.

## 3. Wipe, in this order

1. **Disarm:** `$FS done` when `state.json` exists (guard off, stage guard
   released).
2. **PRs:** for each open PR,
   `gh pr close <N> --comment "> Generated by the factory. Closed by factory reset."`.
3. **Remote branches:** `git push origin --delete <branch>` for each.
4. **Issues and board:** `"$BOARD" reset`. It closes open factory issues as
   not planned with a comment, strips the `factory:issue` key marker from
   every factory issue (else a new run's `board create` would reuse an old
   issue with the same key), and deletes the factory Project.
5. **Local branches:** `git switch <default>`, then `git branch -D <branch>`
   for each.
6. **Docs:** `git rm -r -q -- <tracked doc paths>`, then `read skill://commit`
   and run it. Skip when there are none.
7. **Local files:** `rm -rf .factory qa-evidence ~/.omp/factory/<repo>
   ~/.cursor/factory/holdout/<repo>`.

A step that fails: report its output, run the remaining steps that do not
depend on it, and list what is left in the report.

## 4. Verify and report

Each must hold; print the evidence:

- `.factory/` and `qa-evidence/` are gone; `docs/factory/` is not in
  `git ls-files`.
- `"$BOARD" list` prints nothing.
- No `factory/*` branch in `git branch --list 'factory/*'` or
  `git ls-remote --heads origin 'refs/heads/factory/*'`.
- `gh pr list --state open --search "head:factory/"` is empty.

End with: the docs-removal commit's short sha and subject, that the user
pushes `<default>` themselves, and *Run `/skill:factory` with the new prompt
to start from requirements.*
