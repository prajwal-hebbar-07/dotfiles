# Design grill coverage: <project>

A category is `covered` only when `design.md` says what is decided there, and
`n/a` only with the user's own reason. `open` blocks the end of the grill.
Colour, type and other styling are deliberately not here; they are reviewed in
Paper.

Status: `open` → `covered` · `n/a` · `deferred`.
