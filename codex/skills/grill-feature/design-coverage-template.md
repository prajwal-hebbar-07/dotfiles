# Feature grill coverage: #<n> <title> · design

A category is `covered` only when design.md says what is decided there, and
`n/a` only with the user's own reason. `open` blocks the end of the grill.
Colour, type and other styling are deliberately not here: the feature reuses
the app's look, and the boards are reviewed in Paper.
